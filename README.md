# мрія — простір твоєї краси

Готовий до демонстрації адаптивний сайт вигаданого київського салону краси. React 19, TypeScript, Vite, React Router. Інтерфейс українською мовою, ціни виключно у гривнях.

> **Портфолійна демоверсія, а не сайт діючого салону.** Усі ціни умовні й не є реальним прайсом або пропозицією послуг. Назва салону, команда, адреса, контакти, графік, відгуки та оцінки вигадані або наведені як ілюстрація. Форма запису **нічого нікуди не надсилає** та не створює реального бронювання. Оплата, SMS і листи відсутні.

## Позначення демоверсії

- На кожній сторінці — верхнє повідомлення «Демоверсія для портфоліо» та пояснення в підвалі.
- Біля цін і на сторінці послуг — повідомлення, що суми умовні.
- Перед записом та після підтвердження — явне повідомлення, що запис нікуди не надіслано.
- На сторінці контактів — позначення вигаданої адреси, телефону й email; номер та email не запускають дзвінок або надсилання листа.
- `/demo` — повне пояснення статусу проєкту, вигаданого контенту та роботи форми.
- У назвах вкладок і метаданих також зазначено демостатус; HTML містить `noindex, follow`.

## Запуск

```sh

npm run dev
```

У Windows PowerShell із забороненим запуском `.ps1` використовуй `npm.cmd` замість `npm`.

```sh
npm run build
npm run preview
```

## Сторінки

- `/` — головна з авторськими 3D clay-композиціями, послугами, командою, демовідгуками та FAQ.
- `/services` — 14 послуг, фільтри, пошук, фіксовані ціни та перехід до запису.
- `/team` — майстрині, фільтрація за спеціалізацією та запис до конкретної майстрині.
- `/about` — концепція, цінності та простір салону.
- `/contacts` — українські демонстраційні контакти, мапа, маршрут.
- `/booking` — трикрокова форма та керування демозаписами.
- `/privacy` — інформація про локальне збереження даних.
- `/demo` — пояснення демоверсії для портфоліо, умовних цін, контактів і запису.
- Невідомі адреси — сторінка 404.

Для публікації налаштуй хостинг так, щоб невідомі шляхи повертали `index.html` (SPA fallback). Наприклад, Netlify використовує файл `public/_redirects`, включений у проєкт.

## Демонстраційний запис

**Без backend і без реального бронювання.** Це явно вказано перед формою, у підтвердженні та в підвалі сайту.

1. Послуга й сумісна майстриня.
2. Дата в межах наступних 60 днів, час за Києвом.
3. Ім’я, номер у форматі +380, необов’язковий коментар і згода.

Розклад враховує тривалість процедури, години 09:00–20:00, умовно зайняті інтервали та попередні демозаписи. На поточний день доступний час щонайменше через годину. Перед збереженням доступність перевіряється повторно. Після підтвердження можна завантажити `.ics` із позначкою «ДЕМО», створити ще один запис або скасувати збережений. Видалення всіх записів прибирає також контактні дані.

Дані зберігаються **тільки в localStorage поточного браузера**, ключ `mriia.demo-bookings.v1`. Форма не надсилає мережевих запитів, SMS чи листів і не приймає оплату. Для тестування: `Марія`, `+380 00 000 00 00`.

## Дизайн та ресурси

У початковому проєкті дизайн надано у файлі `DESIGN (2).md`; реалізація використовує саме його палітру, кремове тло, типографіку Inter 500 для заголовків, радіуси, кольорові картки й світлий підвал. Plain Black замінено на Inter згідно з дозволеним у документі варіантом. Шрифти постачаються локально через `@fontsource-variable/inter`. Авторські 3D-композиції створені Three.js і попередньо відрендерені в локальні PNG: відвідувачам не потрібен WebGL, а бібліотека Three.js не входить у клієнтський JavaScript.

Фотографії Unsplash, ілюстрації та шрифти включено в проєкт і завантажуються локально. Інтерактивна мапа — OpenStreetMap, маршрути — Google Maps; для них потрібне інтернет-з’єднання. Імена майстринь, описи, відгуки, контакти та оцінка вигадані для демонстрації.

Вихідний код композицій: `src/components/ClayScene.tsx`. За потреби перегенеруй ілюстрації й фотографії командою `npm run assets` після встановлення Chromium для Playwright. Для звичайного запуску та збірки генерація не потрібна.

## Перевірки

```sh
npx playwright install chromium
npm test
```

Сценарії перевіряють маршрути, адаптивність, мобільне меню, пошук і фільтри, передачу обраної послуги/майстрині, валідацію українського номера, збереження після перезавантаження, блокування зайнятого часу, завантаження календаря та видалення даних. Проєкти запускаються в desktop і mobile Chromium.
